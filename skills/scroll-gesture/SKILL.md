# 滚动手势

## 先量，再定阈值

在目标环境的浏览器里打开 `<本技能目录>/scripts/input-probe.html`（`file://` 即可；远控就在远端开），按平时习惯滚动十几秒，点“复制”取回 JSON。里面有事件频率、间隔 p50/p90、deltaMode、增量分布、鼠标格占比和按 160ms 切出的事件流数。勾选“拦截”可以测自定义手势接管后的输入。阈值要按这些实测数据定，不要凭本机触控板的手感。

## 判断点

- **只设几个停靠点，不停在中间。** 过界翻页只停在原位、接缝（露出邻页摘要）、邻页三处。“停在哪就留在哪”会让短滑把页面卡在两页之间。
- **两段确认防误触。** 第一段手势（含惯性，不论多快）只拉开接缝；接缝停稳后，新的一段手势才是确认。确认是带阻尼的短距离拉动，越过阈值即提交，不够就弹回接缝。
- **用“力度”而不是“距离”判定确认。** 确认量随时间衰减（τ≈0.4s），阈值约 220px 输入：轻滑、慢滑和触控板惯性追不上衰减，弹回；快推、连滚三格、甩动越过。鼠标单格不该直接翻页。
- **弹回等待要长于远控的事件间隔。** 远控每 150–200ms 一簇，停手判定（≈260ms）和衰减都要让这样的连续格累积得上去；用探针的间隔 p90 校准，不要用“先安静 N ms 才算第二次”卡住它们。
- **每段动画都能被接住。** 弹簧、滑行、提交动画都要能被下一次滚轮或触摸从当前位置接住；提交放在动画落地之后，中途打断就不提交。
- **把鼠标格和触控板分开处理。** 增量 ≥40px 或 deltaMode≠0 的算鼠标格，缓动到目标位置（指数跟随，τ≈50ms），否则在 Windows 上会整格跳；触控板的小增量直接跟随，缓动反而发飘。
- **只接管过界的部分。** 内容到边、并且没有可滚动的内层元素时才接管；往回滚要立刻交还原生滚动。不要为了“平滑”劫持整页原生滚动：浏览器本来就会平滑鼠标格，劫持会损害可访问性和虚拟列表。
- **绘制放在 React 渲染之外。** 每帧直接写 transform，进度只写到少数叶子元素，React 只在阶段变化时渲染。
- **测试覆盖快、慢、轻三种输入。** 在 jsdom 里用 reduced-motion 让动画瞬间落地，再断言终态：一次猛滚只停在接缝；“每 100ms 轻滑一点”持续两秒也不翻页且落回接缝；“每 180ms 滚一格”的远控输入能翻过去。真浏览器用例里滚轮会缓动，读进度要轮询，不要事件后立即读。
